# 🚀 Crypto & Forex Signal Generator

An AI-powered trading signal generator using technical indicators and machine learning.

## 🔥 Features
- Fetch crypto & forex data
- RSI, EMA, MACD indicators
- Rule-based signals
- ML-based predictions
- Interactive charts (Plotly)
- Streamlit dashboard

## 🛠 Tech Stack
- Python
- Streamlit
- Plotly
- Scikit-learn
- Binance API / Twelve Data API

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run frontend/app.py
